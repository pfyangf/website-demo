# 第三版结构重做

用户反馈上一稿仍像“换了个颜色”，要求结构有突破。保留前两版和六项导航内容，但推翻 C 的统一段落骨架。

视觉母题取自“星脉”：以环形脉冲表达联结。使用 design-taste-frontend 的 one-motif 方向，保留已确认配色与字体，放弃依赖未经提供的客户摄影。所有网络与轨道图形为概念插图，不当作实时数据、地理定位或业绩证据。

新结构：全屏点阵网络中的中央标题 → 浅色整屏品牌宣言 → 四块无缝拼合的业务矩阵 → 横跨页面的四地路线图 → 三联研究版面 → 明亮招聘横带 → 大字联系收尾。菜单改为全屏展开，取消原横排导航和左文右图。

关键交互：业务展开/收起，城市点击/键盘切换，完整菜单，三版比较。Canvas 在减少动效设置下静止、离屏不计算图形，清理动画帧与观察器。

验证：独立静态构建，320/390/768/1024/1440 宽度，地图标签边界，页面脚本错误，交互、Canvas 动效与三版比较。前两版哈希不变。上一稿 C 备份在 outputs/design-share/third-before-spatial-redesign.html。
