# 星脉首页设计稿

入口：pulsar-design.html。独立视觉预览，不替换现有 static-site。

## 本稿

- 品牌名称使用星脉，公司全称保留星脉发展有限公司。
- 以参考首页的跨境投资业务为内容基础，重新设计首页叙事与排版。
- 深海蓝、银白、少量金色，四城网络与轨道图形表达品牌。
- 中文优先微软雅黑，手机端改为单列。
- 首屏轨道缓慢运动，减少动态效果时关闭。
- 标志为概念示意，文案为待确认设计提案，城市及邮箱依据初稿，尚未核实。
- 本稿为首页视觉评审，语言选择及部分导航是视觉示意；业务行暂跳到投资者关系区。未完成内页、多语言、表单、数据接口。
- 投资组合、资讯、管理层及披露文件暂无材料，暂不虚构；确认资料后补充对应页面。
