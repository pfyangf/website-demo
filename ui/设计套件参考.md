# 本轮设计参考

已读取本机 OpenDesign 随安装提供的 Linear、Stripe 设计体系，以及 contact-widget 联系组件说明。本轮以 Linear 的暗色层次、精密排版、细边框为主要依据，保留星脉深蓝与金色；没有套用 Stripe 的紫色或品牌字体。

更新：香港中心辐射网络、四大业务模块及独立技术图形、可展开业务内容、滚动入场、进度线、城市节点弹窗、联系信息卡。业务架构按用户提供的图片更新。

联系卡中的邮箱来自初稿，待确认。二维码、电话、地址未提供，不虚构。语言、资讯及招聘等仍为设计示意。

技术图形为概念视觉，不代表实际投资收益或业务数据。当前会话无 OpenDesign MCP 工具，本轮直接调整独立 HTML 设计稿，未使用云额度。
